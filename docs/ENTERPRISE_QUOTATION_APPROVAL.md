# 企业级报价、折扣与毛利审批

上海如静知华信息科技有限公司（[知华科技](https://www.zhuatech.cn/)）为 CRM 增加报价前置治理，将商机真实性、价格版本、折扣权限、毛利底线、信用和法务控制集中到一个决策接口。

## 管控闭环

- 校验客户、商机、产品目录、币种税率及客户信用。
- 同时约束人员折扣权限与企业毛利底线，避免低价越权成交。
- 非标准条款自动进入法务路径，高风险报价升级至财务 BP 和销售总监。
- 保留成本测算、报价版本和审批证据，并自动提示有效期跟进。

接口：`POST /api/enterprise/crm/quotation-approval`，返回 `APPROVE / ESCALATE / BLOCKED`、风险级别、审批路径和整改项。
